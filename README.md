Project: Titanic Survival Prediction using Machine Learning

Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

Description:

Performed exploratory data analysis on the Titanic dataset to identify factors influencing passenger survival.
Handled missing values and engineered features such as Family Size, IsAlone, and passenger titles.
Built and evaluated a Logistic Regression model for survival prediction.
Visualized trends and model performance using histograms, bar charts, and confusion matrices.
